# Smart_Trash

## Intro

Smart trash is autonomous monitoring system bult to measure the levels in a trash cans. Once measurements are taken the device then sends them to grafana where they can be remotely monitored. This project was started to help give facilities and matinence more insight into how trash is disposed of on their campus. With levels constantly being monitered staff can see whenj each trash can need to be changed rather then relying on a scheduele.
